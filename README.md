
# MeetMap

A collaborative meetup planning application that helps groups find convenient and interesting places to meet.

Participants can join shared rooms, contribute their starting locations, and explore potential meetup destinations through an interactive map.

## Project Status

🚧 Under active development.

Currently targeting Singapore as the initial supported region.

## Planned Features

- Collaborative meetup rooms
- Shareable room codes and URLs
- GPS and manual location selection
- Interactive shared map
- Multi-modal journey calculations
- Meetup destination recommendations
- Group-based location optimisation

## Technology Stack

**Frontend**
- React
- TypeScript
- Vite
- Tailwind CSS

**Backend**
- Python
- FastAPI
- SQLite

**Mapping**
- OneMap API
